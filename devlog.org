****** Gradle: 9.5.0

Why:
Upper end of Kotlin 2.4.10's fully supported Gradle range.

Constraint:
Must satisfy both Kotlin Gradle Plugin and Android Gradle Plugin
compatibility.

Change when:
A Kotlin upgrade expands the supported Gradle range, or a newer Gradle
release provides a specific benefit we need.

****** Android Gradle Plugin: 9.1.1

Why:
Minimum AGP version supporting Android API 37.0 while remaining only
one patch beyond Kotlin 2.4.10's published fully-tested AGP range.

Constraint:
AGP 9.1.1 supports Android API 37.0 and below.

Change when:
Kotlin officially supports a newer AGP generation, or another Android
SDK level requires it.

****** Gradle runtime JDK: 25

Why:
Current LTS, supported by Gradle, and useful for learning modern JVM
tooling.

Constraint:
Gradle and required plugins must support running on JDK 25.
AGP requires at least JDK 17.

Change when:
A required plugin proves incompatible with 25, or a future JDK becomes
our deliberately selected build runtime.

****** JVM compatibility target: 17

Why:
No current requirement for JVM 21/25 APIs. JVM 17 gives us broader
Desktop/JVM compatibility while allowing the build itself to run on
JDK 25.

Change when:
The application gains a concrete requirement for a newer JVM API or
runtime capability.
